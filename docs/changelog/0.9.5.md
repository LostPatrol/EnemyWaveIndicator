# Enemy Wave Indicator 0.9.5

## English

- Fixes a listen-server HUD failure where joining players could occupy player-controller index 0, causing the host to create no marker widgets.
- Resolves the HUD owner through local controller ID 0, so remote controllers cannot be selected as widget owners.
- Defers marker-pool setup until the local controller exists and makes partial pool construction cleanly retryable.
- Advances the matching native/Blueprint compatibility ABI to `0x90500`; hosts and clients must use the matching 0.9.5 DLL/Pak pair.
- Keeps capture, wave classification, settings, save slot, and the existing region behavior unchanged.
- Offline native, editor, Blueprint, replication, Cook, Pak, and package-integrity gates passed. Real Steam host/client acceptance remains pending.

### Known issue (unresolved)

- Ebonite enemies spawned by Ebonite Outbreak (Warning) (ID 44) are captured but may still be filtered before presentation. Ebonite Outbreak (Event) (ID 37) uses the same enemy family and may also be affected. This release does not change that filtering path.

## 简体中文

- 修复监听服务器房主的 HUD 故障：其他玩家加入后，远端玩家控制器可能占据索引 0，导致房主无法创建任何标记控件。
- 现在通过本地控制器 ID 0 获取 HUD 所有者，远端控制器不会再被错误选作控件所有者。
- 在本地控制器尚未出现时延后创建标记池；若标记池只完成了部分构建，也会先完整清理并在之后安全重试。
- 配套原生／蓝图兼容 ABI 升至 `0x90500`；房主与客机必须使用匹配的 0.9.5 DLL/Pak。
- 刷怪捕获、虫潮分类、设置、存档槽与现有区域行为均未改变。
- 原生离线、编辑器、蓝图、复制、Cook、Pak 与压缩包完整性门禁均已通过；真实 Steam 房主／客机验收仍待完成。

### 已知问题（未解决）

- “矿化爆发（警告）”（ID 44）生成的矿化异虫能够被捕获，但仍可能在显示前被过滤。“矿化爆发（事件）”（ID 37）使用同一类敌人，也可能受到影响。本版本未修改该过滤链路。
