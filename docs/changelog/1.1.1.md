# Enemy Wave Indicator 1.1.1

## English

- Finds compatible game functions and call sites from verified instruction shapes and relationships, reducing failures caused only by code moving after a game update.
- Keeps looking for a late game viewport instead of permanently stopping startup after eight misses.
- Continues startup when a diagnostic log cannot be created; normal builds keep a bounded support log and omit detailed timing and prediction experiments.

## 简体中文

- 根据已校验的指令结构及调用关系定位兼容的游戏函数与调用点，减少更新后仅因代码位置变化导致的失效。

- 游戏视口暂未就绪时继续重试，避免八次未找到后永久停止启动。

- 日志无法创建时仍继续启动；正式构建精简常驻诊断，限制日志大小，并隔离详细计时和预测实验。
