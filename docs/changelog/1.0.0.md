# Enemy Wave Indicator 1.0.0

## English

- Replaces the `[!]` text prefix with the stock Doretta HUD warning icon, loaded at runtime from the installed game. The icon is tinted a fixed red and does not flash with the label.
- English marker default and settings copy for the unannounced wave (自然潮) are now `NORMAL WAVE` / Normal wave. Chinese remains 自然潮.

## 简体中文

- 用游戏原版 Doretta HUD 警告图标替换 `[!]` 文字前缀；图标在运行时从已安装游戏加载，固定为红色，不随文字闪烁。

- 自然潮的英文标记默认和设置文案改为 `NORMAL WAVE` / Normal wave；中文名称不变。
