# Enemy Wave Indicator 0.9.3

发布日期：2026-09-10  
对比版本：`v0.9.0-beta.1`

## 新增

- Mod Hub 界面支持英文和简体中文，虫潮类型清单同步改为双语。
- 支持自然潮与 38 种脚本潮独立配置；新增三提石矿藏、矿化爆发、氪石感染事件潮追踪，核心岩水晶增援并入核心岩事件。
- 每种虫潮可独立启用并自定义提示文字。

## 改进

- 设置页调整为紧凑双列布局，优化标题、分组和正文层级。
- 默认开启大部分虫潮提示；球体 RGB 改用标准化 `0–1` 范围，默认警示文字使用黄—红闪烁。
- 内部资源路径、原生模块目录和发布包统一迁移为 `EnemyWaveIndicator` 名称。

## 修复

- 修复 Mod Hub 较晚加载时页面不出现或不刷新的问题，改为就绪条件轮询并恢复稳定注册元数据。
- 修复首局结束后生命周期巡检停止、第二局不再初始化的问题。
- 支持 `UWorld` 地址复用时重建控制器并重置原生刷怪归因账本。

## 验证边界

- 已通过原生回归、10,000 次自然潮压力测试、全部 38 种脚本潮、UE4 冷启动、1,452 个边界用例、Cook 与打包门禁。
- 用户已在真实游戏中验证 0.9.3，包括完成一局后进入第二局，功能正常。
- 尚未完成双端联机验证，因此本版本仍作为预发布版提供。
