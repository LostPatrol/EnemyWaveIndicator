# Enemy Wave Indicator 0.9.3

Release date: 2026-09-10  
Compared with: `v0.9.0-beta.1`

## English

### Added

- Added English and Simplified Chinese support to the Mod Hub interface and wave-type catalog.
- Added separate configuration for natural waves and 38 scripted wave types.
- Added wave tracking for Tritilyte Deposit, Ebonite Mutation, and Kursite Infection. Core Stone crystal reinforcements now use the existing Core Stone event configuration.
- Added independent enable controls and customizable notification text for every wave type.

### Improved

- Reworked the settings page into a compact two-column layout with clearer title, section, and body typography.
- Enabled most wave notifications by default, standardized sphere RGB values to the `0–1` range, and changed the default warning text to flash between yellow and red.
- Migrated internal asset paths, the native module directory, and release archive naming to `EnemyWaveIndicator`.

### Fixed

- Fixed the Mod Hub page failing to appear or refresh when Mod Hub initializes late by using readiness-based polling and stable registration metadata.
- Fixed the mod stopping its lifecycle checks after the first mission and failing to initialize in the second mission.
- Fixed controller recovery and native spawn-attribution reset when Unreal reuses a `UWorld` address between missions.

## 中文

### 新增

- Mod Hub 界面和虫潮类型清单新增英文与简体中文支持。
- 支持自然潮与 38 种脚本潮独立配置。
- 新增三提石矿藏、矿化爆发、氪石感染事件潮追踪；核心岩水晶增援并入原有核心岩事件配置。
- 每种虫潮均可独立启用并自定义提示文字。

### 改进

- 设置页调整为紧凑双列布局，优化标题、分组和正文字体层级。
- 默认开启大部分虫潮提示；球体 RGB 改用标准化 `0–1` 范围，默认警示文字改为黄—红闪烁。
- 内部资源路径、原生模块目录和发布包名称统一迁移为 `EnemyWaveIndicator`。

### 修复

- 修复 Mod Hub 较晚加载时页面不出现或不刷新的问题，改为就绪条件轮询并恢复稳定注册元数据。
- 修复完成首局后生命周期巡检停止、第二局不再初始化的问题。
- 修复 Unreal 在任务间复用 `UWorld` 地址时控制器无法恢复、原生刷怪归因账本未重置的问题。
