# Enemy Wave Indicator 0.9.4

## English

- Adds exact source classification for Swarmageddon, Exploder Infestation, Scrab Nesting Grounds, Blood Sugar, Rival Presence, Ebonite Outbreak, Lithophage Outbreak, and Haunted Cave.
- Preserves the exact direct spawn point or every game-selected spread center through the existing successful-spawn confirmation path; no predictive marker or new hook is added.
- Adds `BP_CoreCorruption_Crystal` to the existing Core Corruption warning setting.
- Expands the stable catalog from 39 to 47 types and the native/Blueprint ABI to `0x90400`. Haunted Cave remains off by default, as do IDs 1, 6, 32, and 34.
- Keeps the save slot, integer replication protocol, eight-region limit, and natural-wave small-enemy exclusion unchanged.
- Offline, editor, Cook, Pak, and MintCat package gates passed. Matching-host/client acceptance remains pending.

### Known issue (unresolved)

- Ebonite enemies spawned by Ebonite Outbreak (Warning) (ID 44) are captured but currently filtered before presentation, so no marker is displayed. This remains unresolved in 0.9.4. Ebonite Outbreak (Event) (ID 37) uses the same enemy family and may also be affected; this has not yet been confirmed in game.

## 简体中文

- 新增蜂拥浩劫、自爆群袭、掠痕集居、凝血化糖、强敌环伺、矿化爆发（警告）、噬岩体爆发与幽魂不散的精确来源分类。
- 继续通过现有“首个合格敌人成功生成后确认”链路，保留直接生成点或游戏实际选择的每个散布中心；未加入提前预测，也未新增 Hook。
- 将 `BP_CoreCorruption_Crystal` 归入现有“核心侵扰警告”设置。
- 稳定目录由 39 种扩展为 47 种，原生/蓝图 ABI 升至 `0x90400`。幽魂不散默认关闭，ID 1、6、32、34 也继续默认关闭。
- 存档槽、整数复制协议、8 个区域上限和自然潮小型单位排除规则保持不变。
- 离线、编辑器、Cook、Pak 与 MintCat 包门禁均已通过；同版本房主/客机验收仍待完成。

### 已知问题（未解决）

- “矿化爆发（警告）”（ID 44）生成的矿化异虫能够被捕获，但目前会在显示前被过滤，因此不会出现标记。此问题在 0.9.4 中尚未解决。“矿化爆发（事件）”（ID 37）使用同一类矿化异虫，可能同样受影响，尚未完成实机确认。
